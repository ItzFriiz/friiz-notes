# 课程笔记

## 材料与应试

- 按章节融合课件、录音、作业与个人记录，按理解依赖组织，不要求复现授课顺序。重合内容只保留一份，独有例子、图表、教师限定和考核要求不得在压缩中丢失。
- 考核信息未知时只整理知识层次；会影响当前取舍且无法推断的信息才需询问。不要默认课程闭卷或只考公式，也不要把往年试卷代替本学期考纲。
- 内容支持实际考核形式，如论述、证明、计算、论文或展示；自测题和答题模板按需增加，不作为每篇笔记的固定附件。
- 概念理解需要时补直觉或例子，解释深度按通用原则调整；区分概念定义与理论对它的要求，不把待证明的结论写进定义。多人称例子说明各方身份，反例和未解决问题保留原有性质。

## 作业与截止事项

### 检查范围

- 接收新录音、课件、课程通知或整理课程进度时，先查现有作业记录，再扫描本批材料的任务与截止信息。作业检查覆盖课件全文，尤其末页、附录、思考题、Exercises／Homework／Assignment，以及录音中的“交作业”“下周交”“补交”等通知；不能因该页尚未讲授、不纳入知识笔记而跳过。
- 区分已布置的提交任务、仅供自测的思考题与性质待确认的题目。课件出现题目但提交要求不明，提醒“发现题目，是否需交待确认”；有口述布置或催交通知时，不能仍当作普通自测题忽略。
- 核对课程教学平台的作业／通知入口，而不只看课件；按当前任务授权和既有会话操作，登录或验证交给 Friiz。仅整理本地文件或未能访问平台时，明确“教学网未核查”，并将是否存在未下载作业列为待确认。不得把“本批材料未发现”写成“没有作业”。

### 发现后立即通知

- 主 agent 先核对原文，再在当前会话直接提醒，不等整套笔记或审查结束。子 agent 优先回报作业发现及原始定位；报告落盘后立即汇报，不能只夹在长篇提取摘要中。
- 提醒至少包含课程、任务名称／题目范围、截止日期与时间、提交方式／入口及来源位置。缺失字段标待确认，不能补猜。相对日期根据材料日期换算，并保留“按录音日期推算”的身份；模糊转录时间按段定位，不虚构精确秒数。
- 发现截止已过、临近或录音催交而提交状态未知时，先突出该情况，询问／核实提交状态及是否可补交；不能自行判定 Friiz 未交或老师一定收。已完成答案不等于已提交。

### 保存与交付

- 优先在现有课程规则或考核索引前部维护一个作业区，不在每篇知识笔记重复；课程已有独立作业清单则沿用并链接。每项保留任务、截止、提交方式、来源和状态；提交状态只能依据 Friiz 确认或实际提交回执更新。
- 区分“已向 Friiz 提醒”“待确认要求”“已提交”等状态；保留提醒日期，避免每次整理都把旧作业当新任务。任务有变更、此前漏报或出现新催交信息时重新提醒。
- 最终回复把新增／变更作业与需处理的截止事项放在笔记完成情况之前。仅写在索引或工作报告、只说“考核要求已更新”均不算完成提醒。
- 审查者将作业提醒作为独立交付项：从原材料到作业记录逐项核对，检查任务是否漏提、日期是否换算、未知项是否可见、主 agent 是否收到提醒。主 agent 负责实际通知 Friiz。
- 此流程只在处理课程任务时检查和提醒；未设置日历或监控服务就不承诺自动追踪。创建日历、定时任务、自动作答或提交须另获授权。

## 层次与补充

| 层次 | 用法 |
|---|---|
| 重点掌握 | 关键概念、推导、条件和有考核依据的内容；教师强调与整理者判断分别标明 |
| 辅助理解 | 读懂主线所需的背景、直觉和例子 |
| 拓展 | 超出已确认课程范围的内容；考查未知时注明“范围待确认” |

- 分层不构成考核证据，不为凑层次增加内容。已确认不考的内容在标题注明“不考”，证据留在来源或考核汇总，章节末尾不重复放框。
- 重点标记不影响本次要求的内容覆盖；不考内容和已纳入的补充仍需讲清。外部补充注明身份，但不把一节课扩展为无边界专题；扩大范围或额外计算先确认。

## 来源与纠错

- 正文和图注按知识本身组织，不以教师、课件、录音或旧笔记的转述展开。实际使用的资料和截图页码列在文末；必要的考核提示、教师限定及其证据放在课程规则或独立考核汇总，知识正文只保留影响理解的条件和范围。
- 转录同音词结合课件或可靠来源核对；无法确认的关键内容标为存疑。教师、课件和外部资料有实质冲突时分别呈现，并说明对理解或答题的影响。
